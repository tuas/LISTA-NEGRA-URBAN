# Lista Negra Urban

Sistema de gestión de lista negra con sincronización a Google Sheets.

## Características
- Gestión completa de registros (CRUD)
- Sincronización con Google Sheets
- Filtros y búsqueda avanzada
- Exportación a Excel/CSV
- Diseño responsivo

## Cómo usar
1. Configurar el ID de Google Sheet en Configuración
2. Agregar registros manualmente o importar desde Excel
3. Sincronizar con Drive para guardar cambios

## Tecnologías
- HTML5, CSS3, JavaScript vanilla
- Google Sheets API
- LocalStorage para datos temporales
