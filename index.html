Instrucciones para usar Google Sheets como servidor

  1. Crea una hoja de cálculo en Google Drive con los encabezados: ID, Nombre, Documento, Dirección, Motivo, Estado
  2. Ve a Archivo → Compartir → Publicar en web y publica como CSV
  3. Copia el ID de la hoja (parte de la URL entre /d/ y /edit)
  4. Pega el ID en la configuración de la API en esta página
  5. Usa los botones de "Importar desde Google Sheets" para cargar los datos
