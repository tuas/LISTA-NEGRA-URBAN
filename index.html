Instrucciones para usar Google Drive como servidor

  1. Crea una hoja de cálculo en Google Drive con los siguientes encabezados: ID, Nombre, Documento, Dirección, Motivo, Estado
  2. Comparte la hoja de cálculo con acceso de "Cualquiera con el enlace puede ver"
  3. Copia el ID de la hoja (parte de la URL entre /d/ y /edit)
  4. Configura el ID en la función configureGoogleSheet() en el código
  5. Usa los botones de "Importar desde Excel" y "Sincronizar con Drive" para mantener actualizados los datos

Nota: Esta es una implementación de demostración. Para producción, necesitarás implementar autenticación OAuth 2.0 y un backend para manejar las credenciales de forma segura.
